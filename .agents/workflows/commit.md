# Workflow: Safe and Compliant Commits

This workflow triggers the safe commit process by reading and executing the commit skill.

## Procedure
1. Load and execute the commit instructions defined in [skills/commit.md](../skills/commit.md) by reading the file with `IsSkillFile` set to true.
2. Follow all steps in [skills/commit.md](../skills/commit.md) to complete branch verification, CHANGELOG updates, staging, commit message drafting, and executing the commit after user confirmation.
